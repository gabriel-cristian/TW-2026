# Ghid de predare Moodle — S01

1. Completaţi formularul DOCX sau HTML pe parcursul activităţii.
2. Pentru HTML, datele rămân local în browser; folosiţi butonul de validare.
3. Exportaţi/printaţi în PDF şi deschideţi PDF-ul înainte de upload.
4. Redenumiţi fişierul exact conform convenţiei.
5. Deschideţi Assignment-ul din online.ase.ro, folosiţi Add submission şi încărcaţi PDF-ul.
6. Folosiţi acţiunea finală de trimitere dacă este disponibilă; simpla încărcare poate rămâne draft.
7. Reveniţi la pagina Assignment-ului şi verificaţi statusul predării.

Nume fişier:
`TW2026_S01_GRUPA_Nume_Prenume.pdf`

Nu încărcaţi:
- parole / passwords
- token-uri / tokens
- cookie-uri de sesiune / session cookies
- chei API / API keys
- conversaţia Gemini completă / the complete Gemini conversation
