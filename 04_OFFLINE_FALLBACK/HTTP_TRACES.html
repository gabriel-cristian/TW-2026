Fallback offline — trei schimburi HTTP

Aceste urme înlocuiesc numai demonstraţia live. Ele nu sunt dovezi ale calculatorului studentului.

1. Stylesheet

GET /assets/detective.css HTTP/1.1

HTTP/1.1 200 OK
Content-Type: text/css; charset=utf-8

2. Clues

GET /api/clues?case=jar-7 HTTP/1.1

HTTP/1.1 200 OK
Content-Type: application/json; charset=utf-8
X-Case-Id: jar-7

{"caseId":"jar-7","clues":["crumbs","open jar"]}

3. Verdict

POST /api/verdicts HTTP/1.1
Content-Type: application/json

{"suspect":"cat"}

HTTP/1.1 201 Created
Location: /api/verdicts/verdict-1
Content-Type: application/json; charset=utf-8
