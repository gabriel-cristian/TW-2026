# Ținta investigației Detectiv HTTP

Rulați `npm install`, apoi `npm start`. Deschideți URL-ul loopback afișat, panoul Network și selectați **Rulează investigația**.

Folosiți `curl -i` pentru starea, headerele și corpul răspunsului; folosiți `curl -v` când trebuie văzute și headerele cererii. Completați `case-report.json` numai din traficul observat, apoi rulați `npm test`.

Serverul și codul cererilor sunt infrastructură furnizată. Exercițiul modifică numai raportul.
